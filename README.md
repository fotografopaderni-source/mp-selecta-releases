# MP Selecta – download

Qui ci sono solo i programmi di installazione di **MP Selecta** per Windows (nessun codice sorgente).

## Come installare
1. Apri l'ultima versione in **Releases** (a destra) e scarica `MP-Selecta-Setup-X.Y.Z.exe`.
2. Avvialo. Se Windows mostra l'avviso blu "PC protetto", clicca **Ulteriori informazioni** → **Esegui comunque**.
3. Segui l'installazione: non servono permessi da amministratore.

## Aggiornamenti
MP Selecta controlla da solo all'avvio se c'è una nuova versione e chiede se aggiornare.
Puoi anche usare **Impostazioni → Controlla aggiornamenti**.
Le impostazioni (in `%APPDATA%\PaderniRAW`) e le foto non vengono toccate.

Il file `.sha256` accanto all'installer serve per verificare che il download sia integro.
